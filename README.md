# Portfolio App

A modern and responsive portfolio website built with **Next.js**, **React**, **Tailwind CSS**, and modern web technologies. This portfolio showcases my projects, skills, experience, and contact information in an interactive and visually appealing way.

## 🚀 Features

- Responsive design for all devices
- Modern UI/UX
- Smooth animations
- Project showcase section
- Skills and experience section
- Contact form integration
- SEO optimized
- Fast performance with Next.js
- Dark theme design

## 🛠️ Tech Stack

### Frontend

- Next.js
- React
- Tailwind CSS
- Framer Motion
- GSAP

### Tools & Services

- Formspree
- Git & GitHub
- Vercel

## ⚙️ Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd portfolio-app
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

## 📦 Build for Production

```bash
npm run build
npm start
```
